# PATCH v0.34.0 → v0.35.0

Aplique o conteúdo do PATCH sobre a raiz de uma instalação limpa da v0.34.0, preservando a estrutura de pastas.

## Principais mudanças

- `ImportDeliveryOperation`: pátio → inspeção → documentos/liberação → agendamento → caminhão → Gate Out → rodovia → importador.
- `RoadDeliverySceneKit`: ambientes procedurais para retirada, estrada e destino.
- 8 novos laboratórios práticos de importação.
- `PracticalOperationState` migra para `v035` preservando os estados anteriores.
- Gate Out passa a ser uma etapa própria, separada da entrega final.

O projeto continua 100% front-end e compatível com GitHub Pages.
